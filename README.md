# Animated-Overlay

สร้างกรอบ/ป้ายโฆษณาแบบเคลื่อนไหวที่มี**พื้นหลังโปร่งใส** แล้วเอาไปวางบน Track บนสุดของโปรแกรมตัดต่อ (FilmCraft, Premiere, DaVinci, CapCut ฯลฯ)
ทำไฟล์เดียว ใช้กับคลิปไหนก็ได้ ส่วนแผนงานดูได้ที่ [PLAN.md](PLAN.md)

## ติดตั้ง

ต้องมีแค่ [Node.js](https://nodejs.org) รุ่น LTS (18 ขึ้นไป)

FFmpeg ติดมากับโปรแกรมแล้วตอน `npm install` ส่วนการเรนเดอร์ใช้ Microsoft Edge หรือ Google Chrome ที่มีในเครื่องได้ ไม่ต้องติดตั้งอะไรเพิ่ม

**Windows:** ดับเบิลคลิก **`start.bat`** แล้วระบบจะทำให้เองทั้งหมด:
- ติดตั้งส่วนประกอบในครั้งแรก
- เปิดโปรแกรม
- เปิดเบราว์เซอร์ให้อัตโนมัติ

**Mac / Linux / ใช้คำสั่งเอง:**

```bash
npm install        # ครั้งแรกครั้งเดียว (ต้องต่ออินเทอร์เน็ต)
npm start          # เปิด Studio และเปิดเบราว์เซอร์ให้อัตโนมัติ
npm run check      # ตรวจว่าเครื่องพร้อมเรนเดอร์ไหม
```

> ถ้าเจอ `Cannot find package 'playwright'` แปลว่ายังไม่ได้รัน `npm install` (หรือดับเบิลคลิก `start.bat` แทน)

## วิธีสอนใช้ (ทำทีละขั้น)

ส่วนนี้สำหรับคนที่ใช้งานครั้งแรก ทำตามได้เลยโดยไม่ต้องรู้จักโค้ด

### ขั้นที่ 1: เปิดหน้า Studio

- **Windows:** ดับเบิลคลิกไฟล์ **`start.bat`** ในโฟลเดอร์โปรเจกต์ แล้วเบราว์เซอร์จะเปิดหน้า Studio ขึ้นมาเอง
- **Mac / Linux:** เปิด Terminal ที่โฟลเดอร์โปรเจกต์ แล้วพิมพ์ `npm start`

ถ้าเบราว์เซอร์ไม่เปิดเอง ให้เข้าไปที่ **http://127.0.0.1:5173**

> **สำคัญ:** ต้องเปิดหน้าต่างสีดำ (Terminal) ค้างไว้ตลอดตอนใช้งาน ถ้าปิด หน้าเว็บจะใช้ไม่ได้และการเรนเดอร์จะหยุด
>
> ถ้าด้านบนของหน้า Studio มีแถบสีเหลือง **"เครื่องยังไม่พร้อมเรนเดอร์"** ให้ทำตามวิธีแก้ที่เขียนในแถบนั้น

### ขั้นที่ 2: สร้างงานแรกจากเทมเพลต

ที่หน้าแรกจะเห็นหัวข้อ **"สร้างงานใหม่จากเทมเพลต"** ด้านล่าง มี 3 แบบให้เลือก:

| เทมเพลต | เหมาะกับ |
|---|---|
| ชุดโฆษณาคลิปเกม | ป้าย HIGHLIGHT, กล่องโดเนท, กรอบกล้อง, แถบโปรโมชัน |
| ป้ายสปอนเซอร์เด้งเข้ามุมจอ | ป้ายโฆษณาที่เด้งเข้ามาทีละอัน |
| กรอบไฟนีออน | กรอบไฟรอบจอ มีแสงวิ่งหรือกะพริบ |

ทำแบบนี้:

1. ในช่อง **ตั้งชื่องาน** พิมพ์ชื่อภาษาอังกฤษสั้นๆ เช่น `my-first`
2. เลือกขนาด: **แนวนอน 1920×1080** สำหรับ YouTube/คลิปทั่วไป หรือ **แนวตั้ง 1080×1920** สำหรับ TikTok/Shorts/Reels
3. กด **＋ ใช้เทมเพลตนี้** ระบบจะพาไปหน้าปรับแต่งทันที

> ยังไม่แน่ใจว่าชอบแบบไหน กด **ลองปรับดูก่อน** ได้ ลองเล่นได้โดยยังไม่สร้างงาน

### ขั้นที่ 3: ปรับแต่งให้เป็นของคุณ

หน้าปรับแต่งแบ่งเป็น 2 ส่วน: **จอด้านซ้าย** (ดูผลจริง) และ **แผงด้านขวา** (ปุ่มควบคุม)

- **ย้ายชิ้นส่วน:** คลิกค้างที่ชิ้นส่วนบนจอแล้วลาก หรือคลิกเลือกแล้วกดลูกศรบนคีย์บอร์ด (กด Shift ค้างไว้ขยับได้ทีละ 10px)
- **แก้ข้อความ/ราคา/สี:** คลิกชื่อชิ้นส่วนในรายการด้านขวา แล้วพิมพ์แก้ในช่องที่ปรากฏ
- **ข้อความหลายบรรทัด:** ในช่องข้อความกด **Enter** เพื่อขึ้นบรรทัดใหม่ได้เลย กล่องบนจอจะสูงขึ้นตาม และใช้ปุ่ม **จัดข้อความ ซ้าย / กลาง / ขวา** จัดตำแหน่งได้
  - ข้อยกเว้น 1: ข้อความวิ่งเป็นบรรทัดเดียวเสมอ (Enter จะกลายเป็นช่องว่าง)
  - ข้อยกเว้น 2: ช่องข้อความของกล่องประกาศใช้ 1 บรรทัดต่อ 1 ข้อความ
- **เปิด/ปิดชิ้นส่วน:** ติ๊กหรือเอาติ๊กออกหน้าชื่อชิ้นส่วน
- **ปรับขนาด:** เลื่อนแถบ "ขนาด" ของชิ้นที่เลือก
- **ดูแอนิเมชัน:** เลื่อนแถบ "เวลา" หรือกด ▶ เพื่อดูการขยับ ติ๊ก "แสดงทุกชิ้นค้างไว้" ถ้าต้องการให้ป้ายที่โผล่เป็นช่วงๆ แสดงค้างให้ลากได้
- **เปลี่ยนรูปโลโก้:** ที่ช่องรูปของชิ้นที่เลือก ทำได้ 4 แบบ:
  - กด **📁 อัปโหลด** แล้วเลือกรูปจากเครื่อง
  - ลากไฟล์รูปมาวางที่ช่องรูป
  - ลากไฟล์มาวางบนป้ายในจอ
  - กด **🖼 คลัง** เพื่อเลือกรูปที่เคยอัปโหลดไว้

  รูป `.jpg` `.webp` `.gif` `.bmp` `.avif` จะถูก**แปลงเป็น `.png` ให้อัตโนมัติ** และรูปที่ใหญ่เกิน 3840px จะถูกย่อลง ไม่ต้องไปแปลงด้วยโปรแกรมอื่น รูปทั้งหมดจะเก็บไว้ใน `assets/uploads/`
- **เปลี่ยนฟอนต์:** ในส่วน "สีและฟอนต์" กด **📁 อัปโหลด** แล้วเลือกไฟล์ `.ttf` `.otf` `.woff` `.woff2` หรือเลือกฟอนต์ที่เคยอัปโหลดจากรายการ
  - ตัวอักษรที่ฟอนต์นั้นไม่มี (เช่นฟอนต์อังกฤษที่ไม่มีอักษรไทย) จะใช้ Kanit แทนอัตโนมัติ
  - ถ้าฟอนต์มีแค่ไฟล์เดียว ตัวหนา/ตัวเอียงจะถูกจำลองโดยเบราว์เซอร์

**ปุ่มที่ควรรู้**

- **💾 บันทึก** (หรือ Ctrl+S) บันทึกการแก้ไขลงไฟล์ ช่องสถานะด้านบนจะเขียนว่า "บันทึกแล้ว"
- **↶ ย้อนกลับ** (หรือ Ctrl+Z) ยกเลิกการแก้ไขล่าสุด
- **🏠 หน้าแรก** กลับไปหน้า Studio
- **▶ ดูตัวอย่าง** ดูบนพื้นหลังจริง (อัปโหลดรูปหรือคลิปเกมไว้เป็นพื้นหลังได้ในแผงด้านขวา ช่อง "รูป/คลิปพื้นหลังตัวอย่าง" พื้นหลังนี้ไม่ติดไปในไฟล์ที่เรนเดอร์)
- **🎬 เรนเดอร์** สร้างไฟล์วิดีโอ ถ้ามีการแก้ไขค้างอยู่ ระบบจะบันทึกให้ก่อน

> ถ้าค่าที่กรอกใช้ไม่ได้ (เช่น ความยาวเป็นศูนย์) ระบบจะไม่บันทึก คืนไฟล์เดิมให้ และแจ้งข้อความให้แก้

### ขั้นที่ 4: เรนเดอร์เป็นไฟล์วิดีโอ

1. กลับไปหน้าแรก (🏠) หรือกด **🎬 เรนเดอร์** ในหน้าปรับแต่ง
2. รอแถบความคืบหน้าขึ้นถึง 100% (คลิป 10 วินาทีใช้เวลาประมาณ 1 นาที)
3. เมื่อเสร็จ จะขึ้นลิงก์ไฟล์ที่ได้ เช่น `my-first.mov` และ `my-first.webm`
4. ไฟล์ทั้งหมดอยู่ในโฟลเดอร์ `output/` กดลิงก์เพื่อดาวน์โหลดได้เลย

| ไฟล์ | ใช้เมื่อ |
|---|---|
| `.mov` (ProRes 4444) | โปรแกรมตัดต่อทั่วไป ภาพคมที่สุด แต่ไฟล์ใหญ่ |
| `.webm` | ไฟล์เล็ก ใช้กับ OBS หรือเว็บ และบางโปรแกรมที่ไม่รองรับ `.mov` |

### ขั้นที่ 5: เอาไปวางในโปรแกรมตัดต่อ

1. ใส่คลิปเกมของคุณไว้ใน **Track 1** (ชั้นล่างสุด)
2. ลากไฟล์ `.mov` จากโฟลเดอร์ `output/` ไปไว้ใน **Track บนสุด** (ชั้นบนสุด)
3. ลากความยาวให้คลุมคลิปทั้งหมด

ถ้าคลิปยาวกว่าไฟล์ overlay ให้ตั้ง Loop หรือวางไฟล์ต่อกันหลายช่วง เพราะไฟล์วนลูปได้เนียน

**ถ้าพื้นหลังไม่โปร่งใส** (เห็นเป็นกล่องสีดำหรือขาวทับคลิป) ให้ลองใช้ไฟล์ `.webm` แทน หรือเรนเดอร์เป็น PNG ทีละเฟรม

### ขั้นที่ 6: ทำงานชิ้นต่อไป

- **ทำสำเนา:** กด **⧉ ทำสำเนา** ที่งานเดิม แล้วตั้งชื่อใหม่ ใช้เป็นจุดเริ่มต้นแบบเร็ว
- **เปลี่ยนคลิปเกม:** ไม่ต้องแก้ overlay เลย แค่ใส่คลิปใหม่ไว้ Track 1 แล้วใช้ไฟล์เดิมได้เลย
- **เปลี่ยนโลโก้/ข้อความ:** เข้าปรับแต่งอีกครั้ง แก้ แล้วเรนเดอร์ใหม่
- **ลบงาน:** กด **🗑 ลบ** ที่การ์ดงาน แล้วไฟล์งานจะถูกย้ายไปไว้ในโฟลเดอร์ `.trash/` (ย้ายกลับมาได้ถ้าลบผิด) ส่วนไฟล์ที่เรนเดอร์แล้วยังอยู่
- **คลังไฟล์:** ส่วนท้ายของหน้าแรก
  - ดูรูปและฟอนต์ทั้งหมด พร้อมบอกว่างานไหนใช้อยู่
  - ลากหลายไฟล์มาวางอัปโหลดพร้อมกันได้
  - ลบไฟล์ที่ไม่ได้ใช้ได้ (ไฟล์ที่ยังมีงานใช้อยู่จะลบไม่ได้)
- **เปิดโฟลเดอร์:** ปุ่ม **📂** เปิดโฟลเดอร์ไฟล์ที่เรนเดอร์ หรือโฟลเดอร์รูปในเครื่องได้ทันที

| พื้นหลังไม่โปร่งใสในโปรแกรมตัดต่อ | ลองไฟล์ `.webm` หรือ PNG ตามขั้นที่ 5 |

## ใช้งาน

```bash
npm start
```
แล้วเปิด **http://127.0.0.1:5173** ในเบราว์เซอร์ จะเจอหน้า **Studio**:

- **งานของฉัน:** งานทุกชิ้นพร้อมภาพตัวอย่างที่ขยับได้ ทุกงานมีปุ่ม
  - **✏️ ปรับแต่ง:** ลากวาง, แก้ข้อความ/สี/ขนาด, เปิด/ปิดชิ้นส่วน
  - **▶ ดูตัวอย่าง**
  - **🎬 เรนเดอร์:** มีแถบความคืบหน้า เสร็จแล้วมีลิงก์ดาวน์โหลดไฟล์
  - **⧉ ทำสำเนา**
- **สร้างงานใหม่จากเทมเพลต:** ตั้งชื่อ เลือกแนวนอน/แนวตั้ง แล้วกด "ใช้เทมเพลตนี้" ระบบจะเปิดหน้าปรับแต่งให้ทันที หรือกด "ลองปรับดูก่อน" เพื่อลองเล่นโดยยังไม่บันทึก
- ทุกหน้ามีปุ่มกลับหน้าแรก และสลับระหว่างหน้า "ดูตัวอย่าง" กับ "ปรับแต่ง" ได้

แต่ละงานคือไฟล์ `<ชื่อ>.config.json` ในโฟลเดอร์โปรเจกต์ ไฟล์ที่เรนเดอร์ได้จะอยู่ใน `output/`

### ใช้ผ่าน command line

```bash
npm run render                     # ได้ output/overlay.mov (ProRes 4444) + output/overlay.webm
npm run still                      # ได้ output/overlay.png ภาพนิ่งโปร่งใส
npm run composite -- --bg clip.mp4 # ซ้อน overlay ลงคลิปจริง → output/overlay-composite.mp4
npm run render -- -c popup.config.json   # เรนเดอร์งานอื่น
```

ตัวเลือกที่ใช้บ่อย (ใส่หลัง `--` เช่น `npm run render -- --intro`):

| ตัวเลือก | ความหมาย |
|---|---|
| `-c, --config <ไฟล์>` | ใช้ config อื่น เช่น `-c sponsorB.config.json` (ชื่อไฟล์ผลลัพธ์จะตามชื่อ config) |
| `-f, --format prores,webm,png` | เลือกชนิดไฟล์ที่จะได้ |
| `-d, --duration 15` / `--fps 60` | ความยาวและเฟรมเรต |
| `--intro` | มีแอนิเมชันเข้าฉากตอนต้น (ไฟล์จะวนลูปไม่เนียน ใช้ต่อหัวคลิป) |
| `-o, --out <โฟลเดอร์>` | โฟลเดอร์ผลลัพธ์ |

ดู preview บนพื้นหลังจริงได้โดยเอารูปหรือคลิปไปไว้ใน `assets/` แล้วเปิด `http://127.0.0.1:5173/?bg=assets/ชื่อไฟล์.jpg`
หรือใส่ไว้ใน `preview.background` ของ config ก็ได้

## ใส่ใน FilmCraft / โปรแกรมตัดต่อ

1. วางคลิปเกมไว้ **Track 1**
2. ลาก `output/overlay.mov` ไปไว้ **Track บนสุด**
3. ไฟล์วนลูปได้เนียน ถ้าคลิปยาวกว่าให้วางต่อกันหรือตั้ง Loop
4. ถ้าโปรแกรมไม่เห็นพื้นหลังโปร่งใส ลอง `.webm` หรือ PNG sequence (`-f png`)

## แก้ข้อความ / โลโก้ / ตำแหน่ง

แก้ได้ทั้งหมดใน `overlay.config.json` ไม่ต้องแตะโค้ด

| คีย์ใน `elements` | ชิ้นส่วน |
|---|---|
| `highlight` | ป้าย HIGHLIGHT ขวาบน |
| `topDonate` | กล่อง TOP DONATE (`name`, `amount`, `currency`) |
| `sponsorLogo` | โลโก้สปอนเซอร์ (`image` หรือ `text`) |
| `webcamFrame` | กรอบกล้อง ตรงกลางโปร่งใส (`channel`, `label`, `live`, `camSize`) |
| `promoBar` | แถบโปรโมชันด้านล่าง (`logo`, `text`, `oldPrice`, `price`, `unit`, `note`) |
| `ticker` | ข้อความวิ่ง (`tag`, `items`, `speed` px/วินาที) |
| `notice` | กล่องข้อความที่วนเปลี่ยน (`messages`, `secondsEach`) |

- ปิดชิ้นไหนก็ใส่ `"enabled": false`
- ย้ายตำแหน่ง/ขนาดได้ด้วย `"style"` เช่น `"style": { "top": 40, "right": 60, "transform-origin": "right top", "scale": "1.2" }` (ตัวเลขหน่วยเป็น px)
- เปลี่ยนสีทั้งชุดได้ที่ `theme.primary` / `theme.accent` / `theme.panel`
- อัปโหลดโลโก้ได้จากหน้าปรับแต่ง (เก็บไว้ที่ `assets/uploads/`) หรือจะวางไฟล์ไว้ใน `assets/` แล้วแก้ path ใน config เองก็ได้
- ข้อความใส่ `\n` เพื่อขึ้นบรรทัดใหม่ เช่น `"text": "บรรทัดแรก\nบรรทัดสอง"`
- ฟอนต์: ตั้ง `theme.fontFile` เป็น path ไฟล์ฟอนต์ เช่น `"assets/fonts/uploads/MyFont.ttf"`

> โลโก้ใน `assets/logos/` เป็นแค่ตัวอย่าง ให้เปลี่ยนเป็นโลโก้จริงที่ได้รับอนุญาตให้ใช้

## ทำเทมเพลตใหม่

สร้างโฟลเดอร์ `templates/<ชื่อ>/` ที่มี `index.html`, `style.css`, `timeline.js` (ก๊อปจาก `sponsor-gaming` ไปแก้ก็ได้) แล้วตั้ง `"template": "<ชื่อ>"` ใน config

`timeline.js` export ออบเจกต์ที่มี (ใส่ `data-key="<ชื่อใน config>"` ให้ element หลักของแต่ละชิ้น หน้าแก้ไขจะลากได้):
- `build(stage, ctx)`: สร้าง DOM จาก `ctx.config`
- `measure()` (ไม่ใส่ก็ได้): วัดขนาดหลังโหลดฟอนต์/รูปเสร็จ
- `frame(t, ctx)`: จัดท่าทางทุกชิ้นที่เวลา `t` วินาที
- `labels` (ไม่ใส่ก็ได้): ชื่อภาษาไทยของแต่ละชิ้นที่จะแสดงในหน้าแก้ไข
- `fixed`, `dynamic`, `choices`, `labelFor`, `onDuplicate` (ไม่ใส่ก็ได้): ตัวเลือกของหน้าแก้ไข ดูตัวอย่างจาก `sponsor-popup` และ `neon-frame`
- `default.config.json`: config เริ่มต้นที่คำสั่ง `new` จะคัดลอกไปให้ ใส่ `description` ไว้แสดงใน `npm run templates`

**กติกา:** ทุกการขยับต้องคำนวณจาก `t` เท่านั้น ห้ามใช้ CSS animation/transition หรือ timer
ใช้ `ctx.cycle(t, คาบโดยประมาณ)` สำหรับแอนิเมชันที่วนซ้ำ ระบบจะปัดคาบให้หารความยาวลงตัว ไฟล์จึงวนลูปได้เนียน
