# cutkuroko-highlight

สกิล Claude Code สำหรับตัดไฮไลท์คลิปเกม Kuroko no Basket ให้เหลือเฉพาะช่วงที่ตัวละครที่เลือกทำแต้ม แล้วทำเป็นคลิป TikTok แนวตั้งพร้อมโอเวอร์เลย์และซูมเข้าตอนทำแต้ม

## สิ่งที่ต้องมีในเครื่อง

| โปรแกรม | ใช้ทำอะไร | ติดตั้ง |
|---|---|---|
| Claude Code (แอปเดสก์ท็อปหรือ CLI) | เรียกใช้สกิล และอ่านภาพเพื่อหาว่าใครทำแต้ม | claude.com/claude-code |
| FFmpeg (มี ffprobe) | ตัด ต่อ เข้ารหัสวิดีโอ | `winget install Gyan.FFmpeg` |
| Python 3.10+ | รันสคริปต์ `hl.py` | python.org |
| opencv-python, numpy | อ่านเฟรมและจัดภาพแนวตั้ง | `pip install opencv-python numpy` |
| Animated-Overlay (ไม่บังคับ) | สร้าง `vertical.mov` โอเวอร์เลย์แนวตั้ง | `npm install` แล้ว `npm run render:vertical` |

แอปอื่นที่เกี่ยวข้อง (ไม่ต้องใช้ตอนรันสกิล):
- **LDPlayer**: ใช้เล่นเกมและอัดคลิปต้นฉบับ
- **FilmCraft / CapCut**: เอาไฟล์ที่ได้ไปตัดต่อต่อหรือใส่เพลงได้
- **TikTok**: อัปโหลดไฟล์ `_TikTok.mp4` ได้ทันที

## ติดตั้งสกิล

1. คัดลอกโฟลเดอร์ `cutkuroko-highlight` ไปไว้ที่ `C:\Users\<ชื่อผู้ใช้>\.claude\skills\`
2. เปิด `SKILL.md` แก้ตาราง **Defaults** ให้ path ตรงกับเครื่อง (ที่อยู่สคริปต์ และโฟลเดอร์ Animated-Overlay)
3. เปิด Claude Code ใหม่

## วิธีเรียกใช้

พิมพ์ `/cutkuroko-highlight` หรือพิมพ์เป็นประโยค เช่น

> cutkurokoไฮไลท์ คลิป video7 เอาแค่ตอนอาโอมิเนะทำแต้ม ทำ tiktok ซูมด้วย

เปลี่ยนตัวละครได้ เช่น คางามิ คิเสะ มิโดริมะ

## ขั้นตอนที่สกิลทำ

1. **ดูภาพรวม**: ทำภาพตัวอย่างทั้งแมตช์ทุก 2 วินาที อ่านสกอร์บอร์ดว่าทีมเราได้แต้มตอนไหน
2. **หาจังหวะลูกลง**: หาเฟรมดำ/ฉากโลโก้รีเพลย์ที่ขึ้นหลังทำแต้ม
3. **ยืนยันคนทำแต้ม**: อ่านป๊อปอัป `<ชื่อ> 累計得点` (เช่น `青峰 累計得点` = แต้มสะสมของอาโอมิเนะ) ที่ขึ้นหลังลูกลง เก็บเฉพาะลูกที่เป็นของตัวละครที่เลือก
4. **ตัดและต่อรวม**: แต่ละลูกเริ่มก่อนลูกลงประมาณ 10 วินาที และจบตอนป๊อปอัปขึ้น ได้ไฟล์ `<ชื่อ>_Scores.mp4`
5. **ทำแนวตั้ง**: 1080x1920 ที่ 30fps ตัดกลางสนามมาขยาย ส่วนด้านบนและล่างเป็นภาพเบลอ วาง `vertical.mov` ทับ (วนทุก 10 วินาที) ได้ `<ชื่อ>_Scores_TikTok.mp4`
6. **ซูม**: หาตำแหน่งตัวละครทีละลูกจากภาพที่มีเส้นพิกัด แล้วซูมเข้า 2.5–3 วินาทีก่อนลูกลง ได้ `<ชื่อ>_Scores_TikTok_Focus.mp4`
7. **ตรวจงาน**: ดึงเฟรมช่วงท้ายของทุกลูกมาดูก่อนส่ง

ทำไมต้องหาตำแหน่งเอง: วงสีฟ้าใต้เท้าในเกมตามคนที่ถือบอล ไม่ได้ตามตัวละครที่เราเลือก ระบบตามอัตโนมัติจึงจับผิดคน

## ใช้สคริปต์เองโดยไม่ผ่าน Claude

```
python scripts\hl.py --help
python scripts\hl.py sheets video.mp4 --out sheets
python scripts\hl.py popups video.mp4 --times 0:05,0:28 --out popups
python scripts\hl.py cut video.mp4 --segments 0:01-0:07,0:19-0:30 --out out\Scores.mp4
python scripts\hl.py tiktok out\Scores.mp4 --overlay vertical.mov --out out\Scores_TikTok.mp4
python scripts\hl.py tiktok out\Scores.mp4 --overlay vertical.mov --zooms zooms.json --out out\Scores_TikTok_Focus.mp4
```

| คำสั่ง | ทำอะไร |
|---|---|
| `probe` | ดูความยาว ขนาด fps และเสียงของไฟล์ |
| `sheets` | ภาพตัวอย่างหลายช่องพร้อมเวลา (`--crop` เพื่อดูเฉพาะสกอร์บอร์ด) |
| `transitions` | หาเฟรมดำ/ฉากเปลี่ยน |
| `popups` | เฟรมรอบเวลาที่ระบุ ใช้อ่านป๊อปอัปแต้มสะสม |
| `frame` | เฟรมเดียวแบบเต็มความละเอียดพร้อมเส้นพิกัด |
| `cut` | ตัดหลายช่วงแล้วต่อ + ไฟล์ `.segments.json` |
| `endsheets` | เฟรมช่วงท้ายของทุกลูกในไฟล์ผลลัพธ์ |
| `tiktok` | แนวตั้ง 1080x1920 + โอเวอร์เลย์ + ซูม (`--preview <เวลา>` ดูภาพนิ่งก่อน) |

รูปแบบ `zooms.json` (เวลาในไฟล์ที่ตัดแล้ว, พิกัดในภาพต้นฉบับ 1920x1080):
```json
[{"start": 3.2, "end": 6.0, "x": 1180, "y": 520, "zoom": 2.0}]
```

## ข้อจำกัด
- ทดสอบกับคลิป 1920x1080 จาก LDPlayer
- กรอบภาพแนวตั้งคงที่ตรงกลาง ไม่ตามผู้เล่น ถ้าเล่นกันที่ขอบสนามอาจหลุดเฟรม (ปรับด้วย `--fg-width` หรือ `--fg-shift`)
- ระหว่างซูมค้าง กล้องไม่เลื่อนตามตัวละคร
- ไฟล์ผลลัพธ์มักเกิน 30 MB ถ้าจะส่งเข้ามือถือให้ใช้ `--crf 26` ขึ้นไป
