# cutkuroko-highlight

ตัดคลิปเกม Kuroko no Basket ให้เหลือเฉพาะลูกที่ตัวละครที่ผู้ใช้เลือกทำแต้ม แล้ว (ถ้าขอ) ทำเวอร์ชัน TikTok ที่ซูมเข้าตอนทำแต้ม

## Defaults (แก้ให้ตรงกับเครื่อง)

| รายการ | ค่า |
|---|---|
| สคริปต์ | `C:\Users\PC\.claude\skills\cutkuroko-highlight\scripts\hl.py` |
| Python | `python` (ต้องมี opencv-python, numpy) |
| FFmpeg / ffprobe | อยู่ใน PATH |
| โปรเจกต์ Animated-Overlay | `C:\Users\PC\Desktop\CODE\Animated-Overlay` |
| โอเวอร์เลย์แนวตั้ง | `<Animated-Overlay>\output\vertical.mov` (ถ้ายังไม่มี: `npm run render:vertical` ในโฟลเดอร์โปรเจกต์) |
| โฟลเดอร์ผลลัพธ์ | `<Animated-Overlay>\output` |
| ไฟล์ทำงานชั่วคราว (sheets, เฟรม) | scratchpad ของ session |

ด้านล่างใช้ `HL` แทน `python "<สคริปต์>"`

## ข้อมูลที่ต้องรู้ก่อนเริ่ม

ถามเฉพาะที่ผู้ใช้ไม่ได้บอก:
1. ไฟล์วิดีโอ (ถ้าบอกแค่ชื่อ เช่น `video6` ให้ค้นหาเอง)
2. ตัวละคร (ค่าเริ่มต้น: อาโอมิเนะ)
3. ผลลัพธ์: แนวนอนอย่างเดียว / TikTok / TikTok + ซูม (ถ้าพูดว่า "ซูม" "โฟกัส" "ให้เห็นตอนทำแต้ม" = ซูม)

## ชื่อตัวละครในป๊อปอัปแต้มสะสม

หลังทำแต้ม เกมขึ้นป๊อปอัป `<ชื่อ> 累計得点` (แต้มสะสม) ของคนที่ทำแต้ม ใช้อันนี้ยืนยัน **ห้ามเดาจากภาพ**

| ไทย | ญี่ปุ่น | ลักษณะ |
|---|---|---|
| อาโอมิเนะ | 青峰 | ผมน้ำเงินเข้ม ผิวเข้ม |
| คางามิ | 火神 | ผมแดงปลายดำ |
| คุโรโกะ | 黒子 | ผมฟ้าอ่อน ตัวเล็ก |
| คิเสะ | 黄瀬 | ผมเหลือง |
| มิโดริมะ | 緑間 | ผมเขียว แว่น |
| มุราซากิบาระ | 紫原 | ผมม่วง ตัวสูงมาก |
| อาคาชิ | 赤司 | ผมแดง |
| ทากาโอะ | 高尾 | ผมดำ |
| ฮิวงะ | 日向 | ผมดำ แว่น |
| คิโยชิ | 木吉 | ผมน้ำตาล ตัวสูง |
| ฮิมุโระ | 氷室 | ผมดำปิดตาข้างหนึ่ง |

ชุดและทีมเปลี่ยนได้ตามการ์ดในเกม ให้ยึดชื่อในป๊อปอัปเป็นหลัก

## ขั้นตอน

### 1. ดูภาพรวมทั้งแมตช์
```
HL probe VIDEO
HL sheets VIDEO --out <tmp>/sheets --every 2
```
เปิดดูทุกแผ่น จดเวลาที่สกอร์ทีมเราเปลี่ยน ถ้าตัวเลขเล็กอ่านยาก ให้ทำ sheets เฉพาะสกอร์บอร์ดด้วย `--crop x,y,w,h --width 480`

### 2. หาจังหวะลูกลง/รีเพลย์
```
HL transitions VIDEO
```
หลังทำแต้ม เกมมักตัดเข้าฉากโลโก้รีเพลย์ (มีเฟรมดำ) ช่วง `black.start` = จุดจบของช่วงที่จะตัด ถ้าไม่มีเฟรมดำให้ลอง `--scene 0.4`

### 3. ยืนยันคนทำแต้ม
```
HL popups VIDEO --times <เวลาลูกลงแต่ละลูก คั่นด้วย ,> --out <tmp>/popups --before 1 --after 4
```
อ่านป๊อปอัป `<ชื่อ> 累計得点` ทุกลูก เก็บเฉพาะลูกของตัวละครที่เลือก
ตรวจซ้ำ: แต้มสะสมของตัวละครต้องเพิ่มเท่ากับแต้มที่ทีมได้ในลูกนั้น ถ้าไม่ขึ้นป๊อปอัปหรือขึ้นชื่ออื่น = เพื่อนร่วมทีมทำ ตัดทิ้ง

ถ้าไม่มีป๊อปอัปทุกลูก (เช่นโหมด 3v3 สนาม HOUSTON ที่สกอร์บอร์ดเป็น `味方` ซ้าย / `相手` ขวา):
- **ตารางสถิติท้ายเกม** (`データ統計`) บอก PTS ของแต่ละคน ใช้ `HL frame VIDEO --t <เวลาท้ายคลิป> --grid 0` แล้วจับคู่แต้มของตัวละครกับขนาดลูก (2/3 แต้ม) ที่ทีมทำได้
- ป๊อปอัป `LAST GAME <ชื่อ> 累計3Pシュート命中N回` = จำนวนลูก 3 แต้มที่ตัวละครนั้นชู้ตลงแล้ว
- ลูกพิเศษจะมีคัทซีนรูปหน้าตัวละครที่มุมซ้ายบน แล้วเข้าฉากมืด ใช้ดูได้ว่าใครชู้ต
- **วงกลมสีฟ้าใต้เท้า**: คือ **ตัวที่เราต้องการให้จับ** บางครั้งเริ่มมายังไม่ได้กดโฟกัสตัวนั้นอาจรอ5-10วิจะมีวงขึ้นใต้ตัวที่เราต้องการ
- **ตัวละครที่ผู้ใช้เลือก** สังเกตจากวงสีฟ้าใต้เท้า หรือวงสีเขียวน้ำเงิน (teal ring) ใต้เท้าและป้ายชื่อ `SF/SG …` ตัวสีแดงข้างบน แต่ต้องดูว่าใครอยู่ในท่ากระโดดชู้ต/ดังก์ และเช็กป๊อปอัปยืนยัน
- ป้าย `アシスト成功` ลอยเหนือตัวละคร = เขาเป็นคนจ่ายบอล ลูกนั้นเป็นของเพื่อน ตัดทิ้ง
- ท่าพิเศษ (หลุมดำ, ลำแสงเหลือง) = ของคนที่อยู่ใต้ห่วง ไม่ใช่คนที่ยืนไกลห่วง
- ป๊อปอัป `LAST GAME <ชื่อ> 累計得点N` ตอนจบเกมให้แต้มรวมของตัวละคร ใช้บวกลูกที่ตัดเพื่อเช็กว่าไม่ตกหล่น (ตัวอย่าง คิเสะ N=9 = 2+2+3+2 ตรงกับ 4 ลูกที่ตัด)
- ในการจับเวลาตัด ลูกท้ายเกมมีเด้ง `ビデオの再生終了` ตอนจบไฟล์ ให้ตัดก่อนหน้านั้น
ตัวอย่าง (ฮิวงะ): ทีมขวาได้ 18 = 3+3+2+2+3+2+3 ฮิวงะได้ 12 และมีป๊อปอัป 3P ครบ 4 ครั้ง → ลูก 3 แต้มทั้ง 4 ลูกเป็นของฮิวงะ

### 4. ตัดแล้วต่อรวม
แต่ละลูก: เริ่มก่อนลูกลง ~10 วินาที (ไม่ก่อนจบลูกที่แล้ว) จบตอนป๊อปอัปขึ้น ก่อนเข้าฉากรีเพลย์
```
HL cut VIDEO --segments 0:01-0:07,0:19-0:30,... --out <output>/<ชื่อ>_Scores.mp4
```
ได้ไฟล์ `.segments.json` คู่กัน (เวลาในไฟล์ต้นฉบับ ↔ เวลาในไฟล์ที่ตัดแล้ว) ใช้ต่อในขั้น 5–7

### 5. ทำ TikTok (ถ้าขอ)
**ค่าเริ่มต้นไม่ใส่โอเวอร์เลย์** ผู้ใช้มักใส่เองทีหลังในโปรแกรมตัดต่อ ใส่ `--overlay` เฉพาะเมื่อผู้ใช้ขอ (ถ้าขอแต่ยังไม่มี `vertical.mov` ให้รัน `npm run render:vertical` ในโฟลเดอร์ Animated-Overlay ก่อน) ถ้าไม่ใส่ ให้ตัด `--overlay ...` ออกจากทุกคำสั่งด้านล่าง
ดูภาพนิ่งก่อนเรนเดอร์จริง:
```
HL tiktok <cut.mp4> --overlay <vertical.mov> --preview 5 --out <tmp>/tt_check.jpg
```
ดูว่าสกอร์บอร์ดยังเห็น และโอเวอร์เลย์ไม่บังจุดสำคัญ ปรับได้ด้วย `--fg-width` (สัดส่วนที่ตัดจากกลางภาพ ค่าเริ่ม 0.75), `--fg-shift`, `--fg-y`
แล้วเรนเดอร์:
```
HL tiktok <cut.mp4> --overlay <vertical.mov> --out <output>/<ชื่อ>_Scores_TikTok.mp4
```

### 6. ซูมตอนทำแต้ม (ถ้าขอ)
**ห้ามใช้ระบบตามอัตโนมัติจากวงสีฟ้าใต้เท้า** วงนั้นตามคนถือบอล ไม่ได้ตามตัวละครที่เลือก ต้องหาตำแหน่งเองทีละลูก:
```
HL frame <cut.mp4> --t <out_end - 1.5> --out <tmp>/mark_01.jpg --grid 100
```
ดูภาพที่มีเส้นพิกัด หาจุดกึ่งกลางตัวละคร (ถ้าดังก์ให้เห็นทั้งตัวและห่วง ถ้าชู้ตไกลให้จับที่ตัวตอนปล่อยบอล) เขียน `zooms.json` (เวลาในไฟล์ที่ตัดแล้ว, พิกัดในภาพต้นฉบับ):
```json
[
  {"start": 3.2, "end": 6.0, "x": 1180, "y": 520, "zoom": 2.0},
  {"start": 14.1, "end": 17.0, "x": 760, "y": 480, "zoom": 2.0}
]
```
- `start` ≈ `out_end` ของลูกนั้นลบ 2.5–3 วินาที, `end` = `out_end` (ซูมค้างจนจบช่วง แล้วตัดกลับเป็นภาพกว้างตอนขึ้นลูกถัดไป)
- `zoom` 1.8–2.2 กำลังดี
- ตรวจด้วย `--preview` ที่เวลา `start + 1` ของแต่ละลูกก่อนเรนเดอร์จริง
```
HL tiktok <cut.mp4> --overlay <vertical.mov> --zooms zooms.json --out <output>/<ชื่อ>_Scores_TikTok_Focus.mp4
```

### 7. ตรวจงานก่อนส่ง
```
HL endsheets <ไฟล์ผลลัพธ์> --segments-json <cut>.segments.json --out <tmp>/check
HL sheets <ไฟล์ผลลัพธ์> --out <tmp>/check_all --every 6 --width 270
```
ดูทุกแผ่น: ตัวละครอยู่ในเฟรมช่วงซูมทุกลูก ไม่มีภาพเพี้ยน โอเวอร์เลย์ไม่หลุด

## รายงานผล

บอกผู้ใช้: path ไฟล์, ขนาด/ความยาว, ตารางลูกที่ใช้ (ลูกที่ / ช่วงเวลาในต้นฉบับ / สกอร์), ลูกที่ตัดทิ้งพร้อมเหตุผล, จุดที่ควรรู้ (เช่นโอเวอร์เลย์บังสกอร์ฝั่งตรงข้าม, กรอบไม่ตามตัวผู้เล่น)
ไฟล์เกิน 30 MB ส่งเข้ามือถือไม่ได้ ถ้าผู้ใช้ต้องการให้บีบด้วย `--crf 26` หรือสูงกว่า
อย่าลบไฟล์เวอร์ชันก่อนหน้า

## ข้อผิดพลาดที่เคยเจอ
- วงกลมสีฟ้าใต้เท้าคือตัวที่เราต้องการให้จับ แต่อาจต้องรอ 5-10 วิในตอนเริ่มเกมถ้ายังไม่ได้กดโฟกัส
- ลูกท้ายเกมอาจเป็นของเพื่อนร่วมทีม (เช่นผมม่วง) ทั้งที่ตัวละครเรายืนใกล้ ต้องเช็กป๊อปอัปทุกลูก
- ป้ายแดงด้านบนของ vertical.mov อาจทับสกอร์บอร์ดฝั่งตรงข้ามนิดหน่อย
- FilmCraft (`.fcproj`) อ่านได้เพื่อหาว่าใช้คลิปไหน แต่ห้ามแก้ไฟล์โปรเจกต์
