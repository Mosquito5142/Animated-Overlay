# งาน 1: โครงข้อมูลใหม่ + คลังชิ้นส่วน + โปรเจกต์เปล่า

วันที่: 2026-10-21
สถานะ: ออกแบบเสร็จ รอตรวจ

งานนี้เป็นงานแรกในแผนยกเครื่อง Studio ให้ใช้ง่ายแบบโปรแกรมตัดต่อทั่วไป ทั้งหมดมี 4 งาน ทำทีละงาน:

1. **โครงข้อมูลใหม่ + คลังชิ้นส่วน + โปรเจกต์เปล่า** (เอกสารนี้)
2. หน้าจอแบบโปรแกรมตัดต่อ: จอกลาง เครื่องมือซ้าย/ขวา Timeline + Layers ด้านล่าง
3. คลังสื่อ: กดเลือกไฟล์หรือลากวาง รองรับหลายนามสกุล แปลงไฟล์ให้อัตโนมัติ
4. ความสะดวกเสริม: เส้นจัดแนว, safe area, Redo/คีย์ลัด, บันทึกอัตโนมัติ, ท่าวนแบบกลาง, ตั้งค่าขนาดจอ/fps ในหน้าเว็บ

## เป้าหมาย

- เปิดโปรเจกต์ใหม่แบบ **หน้าเปล่า** ได้ แล้วเพิ่ม ลบ ทำสำเนา จัดลำดับ และตกแต่งชิ้นส่วนได้ตามใจ
- ใส่ชิ้นชนิดเดียวกันได้หลายอัน และผสมชิ้นที่มาจากต่างเทมเพลตในงานเดียวได้
- เทมเพลตเดิม 3 แบบกลายเป็น **preset** คือโปรเจกต์ที่มีชิ้นวางไว้ให้แล้ว และแก้ต่อได้อิสระ
- งานที่บันทึกไว้แล้วถูกแปลงเป็นรูปแบบใหม่ให้อัตโนมัติ โดยหน้าตาเหมือนเดิม

## ไม่อยู่ในงานนี้

หน้าจอแบบโปรแกรมตัดต่อและแถบ Timeline สำหรับลาก (งาน 2), ปุ่มเลือกไฟล์รูปและแปลงนามสกุล (งาน 3), เส้นจัดแนว, safe area, Redo, คีย์ลัดเพิ่ม, บันทึกอัตโนมัติ, ท่าวนแบบกลาง, ตั้งค่าขนาดจอ/fps ในหน้าเว็บ (งาน 4), ชิ้นดีไซน์ใหม่ (ปุ่ม Subscribe, นับถอยหลัง, QR ฯลฯ)

## 1. รูปแบบไฟล์โปรเจกต์ (version 2)

ไฟล์ยังชื่อ `<ชื่องาน>.config.json` อยู่ที่ root ของโปรเจกต์

```json
{
  "version": 2,
  "resolution": [1920, 1080],
  "fps": 30,
  "duration": 10,
  "format": ["prores", "webm"],
  "theme": { "primary": "#e3122c", "accent": "#ffd400", "panel": "#141418", "text": "#ffffff", "font": "Kanit" },
  "preview": { "background": "" },
  "layers": [
    {
      "id": "promo-bar-1",
      "type": "promo-bar",
      "name": "แถบโปรโมชัน",
      "hidden": false,
      "start": 0,
      "end": null,
      "enter": { "type": "slide", "from": "auto", "duration": 0.6 },
      "exit": { "type": "none" },
      "style": { "left": 15, "bottom": 60, "scale": "1.2", "transform-origin": "left bottom" },
      "theme": { "primary": "#00c853" },
      "props": { "logo": "assets/logos/game.svg", "text": "แพ็คใหญ่จุใจ", "price": "8,230" }
    }
  ]
}
```

| ฟิลด์ | ความหมาย |
|---|---|
| `layers` | รายการเรียงลำดับ: index 0 อยู่ล่างสุด ตัวท้ายอยู่บนสุด (แผง Layers แสดงกลับด้าน บนสุดอยู่บน) |
| `id` | ไม่ซ้ำกันในโปรเจกต์ รูปแบบ `<type>-<n>` สร้างโดยระบบ |
| `type` | ชนิดชิ้น ตรงกับชื่อโฟลเดอร์ใน `elements/` |
| `name` | ชื่อที่ผู้ใช้เห็นและเปลี่ยนได้ ค่าเริ่มต้นคือ `label` ของชนิด |
| `hidden` | ซ่อนไว้ (ปุ่ม 👁) แต่ยังอยู่ในโปรเจกต์ ไม่แสดงตอนเรนเดอร์ |
| `start` / `end` | วินาทีที่โผล่/หาย ถ้า `end: null` คือแสดงจนจบคลิป ถ้า `end > duration` ส่วนที่เกินจะวนไปแสดงต้นคลิป (เหมือนป้ายเด้งเดิม เพื่อให้วนลูปเนียน) |
| `enter` / `exit` | ท่าเข้า/ออก ดูหัวข้อ 2.3 |
| `style` | ตำแหน่งและขนาด (รูปแบบเดิมของ `applyStyle`) ชิ้นเต็มจอไม่มีฟิลด์นี้ |
| `theme` | (ไม่บังคับ) สีหรือฟอนต์ที่ทับธีมกลางเฉพาะชิ้นนี้ |
| `props` | ค่าเฉพาะของชนิดนั้น ตามที่ประกาศไว้ใน `fields` |

- ฟิลด์ `template` และ `intro` ระดับโปรเจกต์ถูกเลิกใช้
- theme กลางมี 5 ค่า: `primary` (สีหลัก), `accent` (สีเน้น), `panel` (สีพื้นกล่อง), `text` (สีตัวอักษร), `font` (ฟอนต์)

### 1.1 Preset

- `presets/blank.json` คือ `layers: []` พร้อมธีมเริ่มต้น (ใช้ธีมของชุดเกม)
- `presets/sponsor-gaming.json`, `presets/sponsor-popup.json`, `presets/neon-frame.json` ได้จากการแปลง `default.config.json` เดิมของแต่ละเทมเพลตด้วยตัวแปลงในหัวข้อ 1.2 แล้วเก็บเป็นไฟล์ version 2 พร้อม `description`
- การสร้างงานจาก preset คือก๊อปไฟล์ (ตัด `description` ออก) แล้วตั้ง `resolution` ตามแนวนอน/แนวตั้งที่เลือก

### 1.2 การแปลงงานเดิม (version 1 → 2)

ฟังก์ชันล้วน `migrate(v1) → v2` อยู่ใน `src/migrate.js` ไม่มี I/O จึงทดสอบได้

- `loadConfig` ตรวจไฟล์ที่ไม่มี `"version": 2` แล้วเรียก `migrate` ถ้าสำเร็จจะเขียนสำเนาเดิมไว้ที่ `backup/<ชื่อ>.v1.json` ถ้ามีไฟล์ชื่อนี้อยู่แล้วจะใช้ `.v1-2.json`, `.v1-3.json` ... แล้วจึงเขียนไฟล์ version 2 ทับไฟล์เดิม
- ถ้าแปลงไม่ได้ เช่น `template` ไม่ใช่ 3 แบบที่รู้จัก จะ throw พร้อมข้อความภาษาไทย และไม่แตะไฟล์เลย
- เพิ่ม `backup/` ใน `.gitignore`
- ลำดับ layer ยึดตามลำดับ key ใน `elements` เดิม ซึ่งตรงกับลำดับ DOM ที่แสดงอยู่ตอนนี้

|---|---|---|
| sponsor-gaming | `highlight` | `highlight` |

| | `sponsorLogo` | `sponsor-logo` |

| | `promoBar` | `promo-bar` |

| | `notice` | `notice` |
| sponsor-popup | ทุก key | `popup-card` |

กติกาแปลงค่า:

| เดิม | ใหม่ |
|---|---|
| ค่าทุกตัวยกเว้น `enabled`, `style` | ย้ายเข้า `props` |
| `style` | คงไว้ทั้งก้อน |
| `enabled: false` | `hidden: true` |
| `intro: true` | layer ของชุดเกมได้ `start = delay` และ `enter: { type: "slide", offset: [x, y], duration: 0.7 }` ตามตาราง `ENTER` เดิม (ไฟล์ใน repo ทุกไฟล์เป็น `intro: false` กรณีนี้จึงทดสอบด้วย unit test เท่านั้น) |

| ป้ายเด้ง `persistent: true` | `start: 0`, `end: null`, `enter/exit: none` และเก็บ `persistent: true` ไว้ใน `props` (ใช้ท่าลอยแบบแสดงตลอด) |
| theme `secondary` | `accent` (ถ้ายังไม่มี `accent`) |
| ไม่มี `theme.text` | `#ffffff` |
| `name`, `template`, `intro` | ตัดทิ้ง |

## 2. โมดูลชิ้นส่วนและส่วนกลาง

### 2.1 โครงไฟล์

```
elements/
  registry.js              ← รายชื่อชนิดทั้งหมด + หมวด (ใช้ทั้งคลังและตัวตรวจ config)
  text/        index.js style.css
  image/       index.js style.css
  shape/       index.js style.css
  highlight/   top-donate/  sponsor-logo/  promo-bar/  notice/  popup-card/  neon-label/
  webcam-frame/  neon-frame/  neon-bulbs/  neon-corners/  ticker/
presets/
  blank.json  sponsor-gaming.json  sponsor-popup.json  neon-frame.json
templates/_runtime/
  stage.html               ← หน้าเดียวสำหรับ preview / edit / render
  stage.js                 ← แทน runtime.js: โหลดโปรเจกต์, สร้าง layer, เวลา, ท่าเข้า/ออก, ธีม
  timing.js                ← ฟังก์ชันล้วน: การมองเห็น, ความคืบหน้าท่าเข้า/ออก, easing, cycle

```

โฟลเดอร์ `templates/sponsor-gaming/`, `templates/sponsor-popup/`, `templates/neon-frame/` ถูกลบหลังย้ายชิ้นส่วนครบแล้ว (กู้คืนได้จาก git)

### 2.2 สัญญาของโมดูลชิ้นส่วน

```js
export default {
  type: 'promo-bar',
  label: 'แถบโปรโมชัน',
  category: 'banner',          // basic | banner | frame | ticker
  icon: '🏷️',
  fullscreen: false,            // true = เต็มจอ ไม่มี style ลากไม่ได้
  defaults: { props: { ... }, style: { ... } },
  fields: {
    logo:  { label: 'โลโก้', type: 'image' },
    text:  { label: 'ข้อความ', type: 'text' },
    // type: text | textarea | number | color | boolean | select (choices) | image | list | messages | size
  },
  build(root, props, ctx) { return state; },
  measure(state, ctx) {},        // ไม่บังคับ
  frame(state, t, span, ctx) {}, // ท่าวนของชิ้นเอง
};
```

- `root` คือ `<div class="el-<type>">` ที่ส่วนกลางสร้างให้ ส่วน CSS ของชิ้นต้องอยู่ใต้ `.el-<type>` เท่านั้น
- `t` คือเวลาของทั้งคลิป (ใช้กับ `ctx.cycle(t, period)` เพื่อให้วนลูปเนียน)
- `span = { start, end, local, p, showAll }` โดย `local` คือวินาทีนับจากตอนชิ้นโผล่ และ `p` คือ 0..1 ตลอดช่วงที่แสดง ใช้กับตัวเลขนับขึ้น แถบเวลาของป้ายเด้ง และแสงวิ่งหลังเด้งเข้า
- `fields` เป็นตัวกำหนดแผงคุณสมบัติ และใช้แทน `FIELD_LABELS` + การเดาชนิดจากค่า ใน `editor.js` เดิม
  - `list` = รายการข้อความ กดเพิ่ม/ลบทีละแถว
  - `messages` = รายการ {หัวข้อ, ข้อความ} สองช่องต่อแถว
  - `image` = ช่อง path ในงานนี้ งาน 3 จะเพิ่มปุ่มเลือกไฟล์
- กติกาเดิมยังใช้: ทุกท่าทางคำนวณจาก `t` เท่านั้น ห้ามใช้ CSS animation, transition หรือ setTimeout

### 2.3 ส่วนกลาง (`stage.js`)

แต่ละ layer ถูกห่อ 2 ชั้น:

```html
<div class="layer" data-id="promo-bar-1">  <!-- ส่วนกลาง: style, theme ของชิ้น, การมองเห็น, ท่าเข้า/ออก -->
  <div class="el-promo-bar">...</div>       <!-- ตัวชิ้น: หน้าตา + ท่าวน -->
</div>
```

- **ลำดับการทับ** = ลำดับ DOM ตาม `layers`
- **style** ใส่ที่ `.layer` ด้วย `applyStyle` เดิม ส่วน `scale` และ `transform-origin` อยู่ที่ `.layer` เช่นกัน
- **theme ของชิ้น** ใส่เป็น CSS variable (`--primary` ฯลฯ) ที่ `.layer` ส่วน `font` ใส่เป็น `--font`
- **การมองเห็น:** `hidden` → ไม่สร้างเลย ถ้าเวลาอยู่นอกช่วง `start..end` (รวมการวนเมื่อ `end > duration`) → `.layer` ได้ `visibility: hidden` ยกเว้นในหน้าแก้ไขที่ติ๊ก "แสดงทุกชิ้นค้างไว้"
- **ท่าเข้า/ออก** ใส่ `transform` + `opacity` ที่ `.layer`:
  - `none`
  - `fade`: opacity 0→1 แบบ outCubic
  - `slide`: เลื่อนจาก `offset: [x, y]` ถ้าระบุ หรือจากนอกขอบจอตามทิศ `from` (`auto` = ขอบที่ใกล้ที่สุด) ด้วย outBack และ opacity = min(1, p × 2.5) (ตรงกับ intro เดิม)
  - `pop` (เข้า): สูตรเดียวกับป้ายเด้งเดิม คือเลื่อนจากนอกขอบ + scale 0.7→1 ด้วย outBack และ opacity = min(1, p × 3)
  - `pop` (ออก): เลื่อนออกด้วย inBack + scale 1→0.85 และ opacity × (1 − 0.3p)
  - `fade` / `slide` (ออก): กลับด้านของท่าเข้า
  - ท่าเข้าเล่นทุกครั้งที่ถึง `start` ถ้า `start = 0` และอยากให้วนลูปเนียน ให้ตั้ง `enter: none` (ค่าเริ่มต้นของชิ้นใหม่คือ `none`)
- **ชิ้นเต็มจอ:** `.layer` เต็มจอ ไม่มีการลาก ส่วนท่าเข้า/ออกใช้ได้แค่ `none` / `fade`
- **ป้ายเด้ง:** ท่าลอยขึ้นลงและแสงวิ่งระหว่างค้างยังอยู่ใน `frame()` ของ `popup-card` โดยใช้ `span.local` ส่วนท่าเข้า/ออกย้ายไปส่วนกลาง (การ์ดต้องเลิกเขียน `transform` เองตอนเข้า/ออก)
- `stage.html?mode=render|edit|preview&c=<ชื่อ>` โหลดโปรเจกต์ แล้ว import `/elements/<type>/index.js` และใส่ `<link>` ของ `style.css` เฉพาะชนิดที่ใช้
- `window.overlay = { ready, config, renderFrame }` เหมือนเดิม ส่วน `render.js` เปลี่ยนแค่ URL เป็น `/templates/_runtime/stage.html?mode=render`

### 2.4 ชิ้นพื้นฐานใหม่

| ชนิด | props |
|---|---|
| `text` | `text`, `size` (px), `color` (ว่าง = สีตัวอักษรของธีม), `weight`, `align`, `stroke` (สี), `strokeWidth`, `shadow` (boolean) |
| `image` | `src`, `width` (px, ความสูงตามสัดส่วน), `radius`, `opacity` |
| `shape` | `shape` (rect / circle / line), `width`, `height`, `fill` (ว่าง = สีพื้นกล่องของธีม), `stroke`, `strokeWidth`, `radius` |

ทั้ง 3 ชิ้นไม่มีท่าวนของตัวเอง

## 3. หน้าจอ

### 3.1 หน้าแรก

- หัวข้อ "สร้างงานใหม่" มีการ์ด **⬜ หน้าเปล่า** เป็นใบแรก ตามด้วย preset 3 ใบ
- ช่องตั้งชื่อ แนวนอน/แนวตั้ง และปุ่ม "ลองปรับดูก่อน" (`?c=@<preset>`) เหมือนเดิม
- `POST /__api/new { preset, name, vertical }` (`preset`: `blank` หรือชื่อ preset) และ `GET /__api/templates` คืนรายการ preset
- การ์ด "งานของฉัน" แสดงจำนวนชิ้นแทนชื่อเทมเพลต และลิงก์ไป `stage.html`

### 3.2 หน้าปรับแต่ง (แผงขวาคอลัมน์เดียว จนกว่างาน 2 จะจัด layout ใหม่)

เรียงจากบนลงล่าง:

1. **หัว:** ชื่องาน, สถานะ, ย้อนกลับ, บันทึก, หน้าแรก, ดูตัวอย่าง, เรนเดอร์ (เหมือนเดิม)
2. **เวลา:** ปุ่มเล่น, แถบเลื่อน, "แสดงทุกชิ้นค้างไว้" (เหมือนเดิม)
3. **Layers** + ปุ่ม **＋ เพิ่มชิ้น**
   - แต่ละแถว: 👁 ซ่อน/แสดง, ไอคอน, ชื่อ (ดับเบิลคลิกเพื่อเปลี่ยนชื่อ), ↑ ↓ เลื่อนลำดับ แถวที่เลือกมี ⧉ ทำสำเนา และ 🗑 ลบ (ถามยืนยัน)
   - ชิ้นที่ซ่อนจะเป็นสีจาง และเลิกใช้ checkbox เปิด/ปิดแบบเดิม
   - ตอนว่างจะขึ้น "ยังไม่มีชิ้นส่วน — กด ＋ เพิ่มชิ้น เพื่อเริ่ม" และจอแสดงผลแสดงข้อความเดียวกันจางๆ (เฉพาะโหมด edit)
4. **ชิ้นที่เลือก (inspector)**
   - ชื่อ, พิกัด, ขนาด, คืนตำแหน่ง
   - เวลา: เริ่ม, จบ + ☑ "จนจบคลิป"
   - ท่าเข้า: ชนิด / ทิศ / ความยาว
   - ท่าออก: ชนิด / ความยาว
   - สีของชิ้นนี้: ทุกค่าธีมแสดงเป็น "ใช้สีธีม" จนกว่าจะเปลี่ยน และมีปุ่ม ↺ กลับไปใช้สีธีม
   - ค่าของชิ้นตาม `fields`
5. **ธีมของโปรเจกต์:** สีหลัก, สีเน้น, สีพื้นกล่อง, สีตัวอักษร, ฟอนต์
6. **ทั่วไป:** ความยาวคลิป, พื้นหลังตัวอย่าง

- คลิกพื้นที่ว่างบนจอ = ยกเลิกการเลือก
- ทุกการแก้ไขเข้า history (ย้อนกลับได้) เหมือนเดิม
- ทำสำเนา: id ใหม่, ชื่อเติม " (สำเนา)", เลื่อน 40px, วางเหนือชิ้นเดิม ถ้าชิ้นมีช่วงเวลาไม่เต็มคลิป (เช่น ป้ายเด้ง) ให้ต่อเวลาหลังชิ้นเดิมแบบ `onDuplicate` เดิม

### 3.3 หน้าต่างคลังชิ้นส่วน

- เป็น modal แบ่ง 4 หมวด:
  - **พื้นฐาน:** ข้อความ, รูปภาพ, กล่อง/รูปทรง
  - **ป้ายและกล่อง:** HIGHLIGHT, TOP DONATE, แถบโปรโมชัน, กล่องประกาศ, การ์ดสปอนเซอร์เด้ง, ป้ายนีออน, โลโก้สปอนเซอร์
  - **กรอบ:** กรอบกล้อง, กรอบนีออน, หลอดไฟรอบขอบ, มุมกรอบ
  - **ข้อความวิ่ง:** ข้อความวิ่ง
- แต่ละการ์ดมีไอคอน + ชื่อ กดแล้วจะเพิ่ม layer ใหม่ไว้บนสุดจาก `defaults` โดยวางกลางจอ (วัดขนาดหลัง mount แล้วตั้ง left/top) ชิ้นเต็มจอจะเต็มจอเลย จากนั้นเลือกชิ้นนั้นไว้ และปิดหน้าต่าง
- ปิดด้วย Esc, ปุ่ม ✕ หรือคลิกนอกหน้าต่าง

### 3.4 การแยกโค้ด editor

`editor.js` (609 บรรทัด) แยกเป็น `editor/index.js` (สถานะ, history, บันทึก, เรนเดอร์, ลาก, คีย์ลูกศร), `library.js`, `layers.js`, `inspector.js` แต่ละโมดูลรับ container element + ตัว store/คำสั่งจาก `index.js` เพื่อให้งาน 2 ย้ายไปวางในแผงใหม่ได้โดยไม่แก้ข้างใน

## 4. ข้อผิดพลาด

| สถานการณ์ | พฤติกรรม |
|---|---|
| `type` ไม่มีใน `elements/` | edit/preview: กล่อง ⚠ "ไม่รู้จักชิ้น xxx" แทนชิ้นนั้น ชิ้นอื่นทำงานปกติ ลบได้จาก Layers / render: ล้มพร้อมชื่อชิ้น |
| `build()` หรือ `frame()` throw | edit/preview: กล่อง ⚠ พร้อมข้อความ error เฉพาะชิ้น / render: ล้ม ไม่สร้างไฟล์ที่ขาดชิ้น |
| โหลดรูปไม่ได้ | เตือนใน console แล้วทำต่อ (เหมือนเดิม) |
| บันทึกค่าที่ใช้ไม่ได้ | `loadConfig` ตรวจ: `version === 2`, `layers` เป็น array, `id` ไม่ว่างและไม่ซ้ำ, `type` ตรง `/^[a-z0-9-]+$/` และมีโฟลเดอร์, `start ≥ 0`, `start < duration`, `end` เป็น null หรือ > `start`, ชนิดท่าเข้า/ออกอยู่ในชุดที่รองรับ, `hidden` เป็น boolean ถ้าผิดจะคืนไฟล์เดิม แล้วแจ้งเป็นภาษาไทย (กลไกเดิมของ `onSave`) |
| แปลงงานเดิมไม่ได้ | ไม่แตะไฟล์ หน้าแรกแสดง error บนการ์ดงานนั้น (`listConfigs` รองรับอยู่แล้ว) |

CLI: `templates` แสดง preset, `new` รับ `--preset <ชื่อ|blank>`, `-c <ไฟล์>` ใช้ได้เหมือนเดิม (แปลงอัตโนมัติตอนโหลด) และ `check` ยังทำงานเหมือนเดิม
